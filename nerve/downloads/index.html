Free Alpha

Nerve is two installable pieces: an extension you get through the Fantasy Grounds Forge, and a Windows companion you download here. You need both, at matching versions.

One half is available

The Windows companion below is published and you can download it now. The Fantasy Grounds extension has not been released yet, so a working setup is not possible today. Both statuses on this page are live — when the extension appears here, it is genuinely available.

Before you download

Check all six, then continue
  • A Windows GM host — Windows 10 / 11 (64-bit).
  • Fantasy Grounds Unity running the 5E ruleset.
  • The Nerve extension from the Forge. The extension alone provides no AI service.
  • The separate Nerve Windows companion, below.
  • Node.js 22 or newer.
  • A compatible external AI application and account. AI access, allowance and costs are not included with Nerve.

This is alpha software. Setup and gameplay behaviour are still being tested, and provider and multiplayer coverage are uneven. Please read the known limitations and the privacy and data-flow page before installing — in particular, selected campaign context is sent to the external AI provider you choose, and that can include GM-only material.

Back up your campaign and start with a test copy. The setup guide walks the install in order.

Both halves must be the same version

Nerve is an extension and a companion, and they must be the same version. Open Fantasy Grounds and read the line it prints on load — Nerve Adapter v0.68.7 loaded. — then download the companion that matches it.

What improved in this release

  • Manual Work Mode — Make native Fantasy Grounds bookkeeping changes without generating automatic AI cues. Deliberate Call Nerve requests stay available.
  • Version safety — The extension and companion now require an exact version match, and say which of the two needs updating.
  • Cleaner rolls — Table results and staged skill, ability-check and saving-throw messages settle into one follow-up instead of duplicate paid cues.
  • Safer combat flow — Attack and result stages settle together; completed native damage does not repeat or end the player's turn; remaining effect work stays available; and a final defeat preserves wounds, effects and roster entries until an explicit end-turn.
  • Better continuity — A confirmed current-room Story context can survive combat and a session resume without repinning.
  • Safer recovery — Stale decisions are rejected without duplicate actions, and a claimed provider or listener failure is closed out cleanly rather than resubmitted as another possibly billed request.
  • Clearer controls and installation — Session and AI controls are easier to read, and the custom-app configuration launcher is now installed correctly.

    Verifying what you downloaded

    Every published ZIP ships with a matching .zip.sha256 file. Each digest is computed at build time from the exact bytes this site serves, so a published checksum and its published file cannot disagree. Verify before extracting — compare the output of the first row against the checksum on the card above:

    Verify the download on Windows
    PowerShell Get-FileHash -Algorithm SHA256 .\Nerve-Windows-Companion-<version>-alpha.zip
    Compare against the SHA-256 shown on that version's card, or the contents of its .sha256 file.

    What you are not downloading

    Only approved end-user files are published here. Review bundles, extracted source folders, playtest logs, campaign snapshots and provider profiles are not public downloads and never will be.

    Two pieces, two update paths

    These update separately, and mismatched versions are a common source of odd behaviour.

    Who updates what
    PieceUpdated byHow
    Nerve extension Fantasy Grounds Install or update the Forge item, then run the Fantasy Grounds updater.
    Nerve companion The companion installer Download the matching ZIP here, extract it completely and run Install-Nerve.cmd.

    Current packaging targets Forge Data installation, not encrypted Vault delivery. Versions must match the release instructions — check release notes before updating one half without the other.

    Rolling back

    Every release listed above keeps its own permanent, versioned address, so rolling back is just installing the older companion and the extension version that pairs with it. We never replace the bytes at an address that has already been published — a new build always gets a new address — so a link or a checksum you saved months ago still resolves to the same file. Per-release known issues and update instructions are on the releases page.

    Developer-preview users

    If you have been running a developer preview, do not just install on top of it. Follow the migration steps first — the old extension folder has to be moved out of the way, or Fantasy Grounds will warn about duplicate copies. Never delete campaign data.
