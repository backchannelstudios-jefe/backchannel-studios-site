Setup guide

Free Alpha

Do these in order. Steps 1 to 5 install the software; steps 6 to 8 connect your own AI account; steps 9 and 10 run and end a session. Skipping ahead is the most common cause of a setup that will not connect.

Before you begin

You need all of these
  • A Windows GM host — Windows 10 / 11 (64-bit). The companion runs on the machine hosting the campaign.
  • Fantasy Grounds Unity running the 5E ruleset.
  • The Nerve extension, installed through the Forge. The extension on its own provides no AI service.
  • The separate Nerve Windows companion.
  • Node.js 22 or newer.
  • A compatible external AI application and account. AI access, allowance and costs are not included with Nerve — your provider bills you, not us.

Selected campaign context and source references are sent to the AI provider you choose, and that can include GM-only material. Read privacy and data flow and get your group's agreement before you put their campaign through a provider.

Install and connect — ten steps

  1. Back up your campaign, and start with a test copy

    Do not learn Nerve on the campaign you care about. Make a backup, then make a throwaway copy of a campaign and do your first sessions there. Nerve can change campaign records through supported actions, and this is alpha software.

  2. Install the Nerve extension through the Forge, then run the updater

    Add the Nerve item to your Forge library, then launch Fantasy Grounds and let the updater run so the extension is actually downloaded to your machine. Installing the Forge item without running the updater leaves you with nothing installed.

    Current packaging targets Forge Data installation, not encrypted Vault delivery.

    Forge release pending

    The Forge item is not publicly available yet, so this step cannot be completed by new testers today. Downloads shows the current status.

  3. Install Node.js, then download and fully extract the companion

    Install Node.js 22 or newer if you do not have it. Then download the companion ZIP that matches your extension version from Downloads, verify its SHA-256 checksum, and extract the ZIP completely before running anything.

    Extract, do not browse

    Running the installer from inside Windows' zip preview — without extracting first — is a frequent cause of a half-installed companion. Extract the archive to a real folder, then open that folder.

  4. Run Install-Nerve.cmd and answer its prompts

    From the extracted folder, run Install-Nerve.cmd. It will ask which campaign to attach to and what role to configure. Answer with the test campaign from step 1.

  5. Enable Nerve Adapter in Fantasy Grounds and confirm the version

    Launch Fantasy Grounds, enable the Nerve Adapter extension for your campaign, load the campaign, and confirm the version it reports matches the companion you installed. Mismatched halves are the second most common setup failure.

  6. Open Nerve Control → AI Setup and select your provider

    The Nerve control appears in the Fantasy Grounds sidebar with this icon. Open Nerve Control, go to AI Setup, and select the provider you intend to use. If the provider needs local components, use Install / Repair first, then Sign In.

  7. Complete your provider's own sign-in

    Authentication is owned by your provider, not by Nerve. A browser window may not appear at all if you are already signed in — that is normal, not a failure.

    Signing in to the provider's website is not enough

    Being logged in to an ordinary browser chat session does not establish the listener connection Nerve needs. You have to complete sign-in through the AI Setup flow.

  8. Run Test + Use, and check which provider succeeded

    Use Test + Use and confirm both that the test succeeded and that the provider it reports is the one you meant to select. Do not start play on an untested connection.

    Tests and gameplay both consume your provider allowance. Nerve does not meter, cap or pay for that.

  9. Start Nerve and begin a session

    Start Nerve to open a tracked session. New tracked sessions default to Flow Mode. If you would rather approve each action yourself, switch to manual approval before you play rather than during a scene.

    You can stop the connector at any time. Stop Nerve cancels what is in flight — it is not an undo. Anything already applied to campaign records stays applied.

  10. End Session, confirm the connector stopped, and check the records

    Use End Session and confirm the connector has actually stopped. Then inspect the native Fantasy Grounds records for anything an action claimed to change — inventory, currency, quests, combat. Narration is not proof that a record changed.

How updates work

Nerve updates along two separate paths, and they must stay in step:

Two pieces, two update paths
PieceUpdated byHow
Nerve extension Fantasy Grounds Update the Forge item, then run the Fantasy Grounds updater.
Nerve companion The companion installer Download the matching ZIP, extract completely, run Install-Nerve.cmd.

Always check the release notes for the version pairing before updating one half on its own.

Migrating from a developer preview

If you have been running a developer preview build, do not install the packaged extension on top of it. Fantasy Grounds will find two copies and behave unpredictably.

  1. Close Fantasy Grounds completely

    Fully exit — not just the campaign.

  2. Move the old extensions/Nerve folder out of extensions

    Move it somewhere you can get it back from — your desktop is fine. Move it out of the extensions folder entirely; renaming it in place is not enough.

    Never delete campaign data

    This step touches the extension folder only. Your campaigns, characters and modules are somewhere else and must be left alone. If an instruction anywhere tells you to delete campaign data to fix Nerve, it is wrong — tell us.

  3. Install the packaged extension from the Forge

    Then run the Fantasy Grounds updater, as in step 2 above.

  4. Re-run the Forge companion installer

    Run Install-Nerve.cmd from the new companion package so the runtime is repointed at the packaged extension.

If Fantasy Grounds warns you about duplicate Nerve copies, you are seeing the problem these steps fix — come back here rather than deleting anything.

Troubleshooting

Each row is a concrete next step, not a diagnosis. If none of them fit, send us a bug report with your exact error code.

Common problems and what to do next
What you see Likely cause Next step
Nerve controls appear but nothing responds The companion is not installed or not running. The extension cannot reach a provider on its own. Install the companion (steps 3 and 4) and confirm it is running on the GM host.
Sign-in never completes, or no browser opens You are already signed in, or sign-in was done in an ordinary browser tab. No browser window is expected if you are already signed in. Ordinary browser chat sign-in does not establish the listener — redo sign-in through AI Setup.
Responses come from the wrong provider A different provider is selected than the one you signed in to. Run Test + Use and read which provider it reports before playing. Reselect in AI Setup if it is not the one you want.
Version mismatch, or odd behaviour after an update Extension and companion are on different versions. Reload the campaign and confirm the reported version. Check the release notes pairing and update whichever half is behind.
Fantasy Grounds warns about duplicate extensions A developer-preview folder is still in extensions. Follow migration. Move the old folder out to a recoverable backup — do not delete campaign data.
Response is slow, or times out Provider latency, or a request that has already failed. Built-in listeners normally time out after three minutes. Wait it out rather than clicking Call Nerve again — repeat clicks queue more work, they do not speed anything up.
APP_LISTENER_PROTOCOL_FAILED Several causes. On Grok in this candidate, a detailed "Rate limited" message can surface under this code. Read the detail text under the code before concluding anything. A timeout on its own is not proof of subscription throttling. Include the full message in a bug report.
You approved an action but nothing visibly changed The record may have changed without an obvious interface cue — quest completion in particular. Open the native record and check it directly. Quest completion can be updated through supported actions but is not clearly visible in the standard quest interface. If the record really is unchanged, that is a bug worth reporting.
Stop Nerve did not undo what happened Working as designed. Stop Nerve cancels in-flight work; it is not an undo. Correct campaign records manually, checking first so you do not double-apply a change.

Support bundles

The companion ships with Collect-Nerve-Support.cmd, which gathers diagnostic information into a single bundle. Do not attach a bundle to the public feedback form — bundles can contain campaign content and account details. Review the contents yourself, and share one privately only if we ask you for it.
