Nerve 0.68.7 (alpha)

15 September 2026 · Windows 10 / 11 (64-bit) · Fantasy Grounds Unity — 5E

Check your adapter version first

The companion ZIP is published on the downloads page so it is ready the moment the Forge listing updates. Both 0.68.7 halves detect a mismatch and say which one to update, but the pair still has to match to work.

A substantial alpha update focused on safer live play, lower accidental AI usage, clearer setup, and more reliable Fantasy Grounds event handling.

What improved in this release

  • Manual Work Mode — Make native Fantasy Grounds bookkeeping changes without generating automatic AI cues. Deliberate Call Nerve requests stay available.
  • Version safety — The extension and companion now require an exact version match, and say which of the two needs updating.
  • Cleaner rolls — Table results and staged skill, ability-check and saving-throw messages settle into one follow-up instead of duplicate paid cues.
  • Safer combat flow — Attack and result stages settle together; completed native damage does not repeat or end the player's turn; remaining effect work stays available; and a final defeat preserves wounds, effects and roster entries until an explicit end-turn.
  • Better continuity — A confirmed current-room Story context can survive combat and a session resume without repinning.
  • Safer recovery — Stale decisions are rejected without duplicate actions, and a claimed provider or listener failure is closed out cleanly rather than resubmitted as another possibly billed request.
  • Clearer controls and installation — Session and AI controls are easier to read, and the custom-app configuration launcher is now installed correctly.

What this does not promise

  • These changes cut duplicate and bookkeeping cues, so fewer requests are sent. How much that saves depends on your provider, model, play style and retries, so no percentage or dollar figure is claimed here.
  • Narration does not prove that an inventory, currency, quest or combat record was actually changed. Check the native record.
  • Native effect expiry at tied initiative remains a known concern.
  • A Windows GM host running 5E is the supported target. Multiplayer, other operating systems and other rulesets are not certified.
  • AI provider usage is separate from Nerve and may incur charges from that provider.

Before you update

Back up the campaign and your Nerve configuration first. Then update the extension through the Forge, let the Fantasy Grounds updater run, and install the companion carrying the same version.

Nerve 0.67.1 (alpha)

11 September 2026 · Windows 10 / 11 (64-bit) · Fantasy Grounds Unity — 5E

Companion published, extension pending

The Windows companion for this version is available on the downloads page. The Fantasy Grounds extension has not been released yet, so this version cannot be run end to end. Forge moderation and clean-profile public installation have not been validated, and this page will not imply otherwise.

Requirements for this release

  • Windows GM host — Windows 10 / 11 (64-bit).
  • Fantasy Grounds Unity running the 5E ruleset.
  • Node.js 22 or newer.
  • A compatible external AI application and account. Not included, not billed by us.
  • Matching extension version 0.67.1, free on the Forge.

Changes in this candidate

  • Installer ownership fix — implemented and tested offline.

Known issues in this candidate

  • Narration does not prove that an inventory, currency, quest or combat record was actually changed. Check the native record.
  • Inventory, payment and reward transactions are not a complete workflow. Check the record before correcting anything manually — an unchecked correction may duplicate an update that already applied.
  • Quest completion can be updated through supported actions, but completion is not clearly visible in the standard quest interface.
  • On Grok, a detailed "Rate limited" message can surface underneath APP_LISTENER_PROTOCOL_FAILED. Read the detail text — a timeout on its own is not evidence of subscription throttling.
  • Built-in listeners normally time out after three minutes. Avoid repeated Call Nerve clicks while responding; they do not speed up the current request.
  • Story Cues supply reference context only. They do not move characters and do not automatically reveal records.
  • Provider and multiplayer testing is incomplete. We are not turning a handful of local comparisons into provider rankings or upgrade recommendations.

Updating to this release

  1. Back up the campaign first.
  2. Update the Forge item, then run the Fantasy Grounds updater so the extension is actually downloaded.
  3. Download the matching companion ZIP, verify its checksum, extract it completely and run Install-Nerve.cmd.
  4. Load the campaign and confirm the reported version matches.

Coming from a developer preview? Follow the migration steps before installing — the old extensions/Nerve folder has to be moved out of extensions first. Never delete campaign data.

Earlier releases

0.67.1 (alpha) was the first public companion release, and it stays downloadable for as long as anyone is running the extension that pairs with it. Developer-preview builds circulated privately during development and are not published here; if you are running one, treat the migration steps above as required rather than optional.

Once releases are published, each approved version keeps its own permanent, versioned address so you can roll back. We never replace the bytes at an address that has already been published, and older releases carry a compatibility warning where they need a different extension version.
