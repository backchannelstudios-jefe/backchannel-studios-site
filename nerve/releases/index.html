The Fantasy Grounds extension and the Windows companion are versioned together. Running one half ahead of the other is a supported way to get confusing behaviour, so check this table before updating either.

0.67.1-alpha — release candidate

not yet published · Windows 10 / 11 (64-bit) · Fantasy Grounds Unity — 5E

Not yet a public release

This version is a candidate. The product owner has to approve the actual public release and its artifacts before any download link here goes live. The installer ownership fix is implemented and tested offline; Forge moderation, download and update delivery, and clean-profile public installation have not been validated yet, and this page will not imply otherwise.

Requirements for this release

  • Windows GM host — Windows 10 / 11 (64-bit).
  • Fantasy Grounds Unity running the 5E ruleset.
  • Node.js 22 or newer.
  • A compatible external AI application and account. Not included, not billed by us.
  • Matching extension version 0.67.1-alpha from the Forge.

Changes in this candidate

  • Installer ownership fix — implemented and tested offline.

Known issues in this candidate

  • Narration does not prove that an inventory, currency, quest or combat record was actually changed. Check the native record.
  • Inventory, payment and reward transactions are not a complete workflow. Verify before correcting anything manually, or you will double-apply the change.
  • Quest completion can be updated through supported actions, but completion is not clearly visible in the standard quest interface.
  • On Grok, a detailed "Rate limited" message can surface underneath APP_LISTENER_PROTOCOL_FAILED. Read the detail text — a timeout on its own is not evidence of subscription throttling.
  • Built-in listeners normally time out after three minutes. Repeated Call Nerve clicks while a response is in flight do not help.
  • Story Cues supply reference context only. They do not move characters and do not automatically reveal records.
  • Provider and multiplayer testing is incomplete. We are not turning a handful of local comparisons into provider rankings or upgrade recommendations.

Updating to this release

  1. Back up the campaign first.
  2. Update the Forge item, then run the Fantasy Grounds updater so the extension is actually downloaded.
  3. Download the matching companion ZIP, verify its checksum, extract it completely and run Install-Nerve.cmd.
  4. Load the campaign and confirm the reported version matches.

Coming from a developer preview? Follow the migration steps before installing — the old extensions/Nerve folder has to be moved out of extensions first. Never delete campaign data.

Earlier releases

There are no earlier public releases. Developer-preview builds circulated privately during development and are not published here; if you are running one, treat the migration steps above as required rather than optional.

Once releases are published, each approved version keeps its own permanent, versioned address so you can roll back. We never replace the bytes at an address that has already been published, and older releases carry a compatibility warning where they need a different extension version.

Every version number on this site is generated from a single release record, so the setup, downloads and release pages cannot drift apart. Fantasy Grounds and the Forge are operated by SmiteWorks, which has not endorsed or certified this product.
